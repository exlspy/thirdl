## Что это

**CodeScaffold** генерирует вложенные управляющие конструкции из одной короткой строки на мини-языке (DSL).
Это не набор готовых сниппетов: строка разбирается в дерево (AST), для которого код строится рекурсивно
под выбранный язык, с учётом настроек отступов редактора.

```
for i 0..n; if i%2==0 else; while x<3
```

превращается (TypeScript) в:

```ts
for (let i = 0; i < n; i++) {
    if (i%2==0) {
        while (x<3) {
            |            <- курсор уже здесь
        }
    } else {
        |                <- Tab переходит сюда
    }
}
```

## Возможности

| Команда | Горячая клавиша | Что делает |
|---|---|---|
| `CodeScaffold: Сгенерировать конструкцию` | `Ctrl+Alt+G` (`Cmd+Alt+G`) | Вводите DSL-строку → вставляется код с табстопами. Во время ввода показывается структура или текст ошибки. |
| `CodeScaffold: Обернуть выделение` | `Ctrl+Alt+W` (`Cmd+Alt+W`), контекстное меню | Оборачивает выделенные строки в конструкцию (например, `try finally`), сохраняя их отступы. |
| `CodeScaffold: История шаблонов` | — | LRU-список последних шаблонов (размер — настройка `codescaffold.historySize`). |

### Синтаксис DSL

Сегменты разделяются `;` — каждый следующий вкладывается в предыдущий.

| Конструкция | Запись | Примеры |
|---|---|---|
| Условие | `if <усл> [else]` | `if a > b else` |
| Цикл со счётчиком | `for [var] от..до [step N]` | `for i 0..n`, `for 10`, `for i 10..0 step -1` |
| Цикл по коллекции | `foreach x in <коллекция>` (синоним `each`) | `foreach item in items` |
| Пока | `while <усл>` | `while n > 0` |
| Переключатель | `switch <выр>: a, b, c [default]` | `switch x: 1, 2 default` |
| Функция | `func имя(п1, п2)` (синонимы `fn`, `def`) | `func add(a, b: number)` |
| Исключения | `try [finally]` | `try finally` |

Верхняя граница `for` не включается (`0..n` → `i < n`); отрицательный `step` даёт обратный цикл.

### Поддерживаемые языки

TypeScript, JavaScript, Java, C++, C, Go, Python. Если язык файла не распознан, предлагается выбрать профиль вручную.
Конструкции, которых нет в языке (`try` в C и Go), дают понятное сообщение об ошибке.

## Установка и запуск

```bash
npm install
npm run compile
npm test            # unit-тесты ядра (23 теста, без VS Code)
```

Запуск в режиме разработки: откройте папку в VS Code и нажмите **F5** — откроется окно Extension Development Host.
Сборка установочного файла: `npm run package` (создаст `.vsix`; устанавливается через *Extensions → … → Install from VSIX*).

## Структура проекта

```
src/
  ast.ts          типы узлов AST и DslError
  parser.ts       разбор DSL (конечный автомат + разбор сегментов)
  languages.ts    языковые профили и реестр (Strategy)
  generator.ts    рекурсивная генерация кода и табстопов
  indent.ts       работа с отступами (dedent, общий префикс)
  history.ts      LRU-история шаблонов
  extension.ts    точка входа: команды VS Code
  test/           unit-тесты (node:test)
docs/
  DOCUMENTATION.md   подробная документация по проекту
  architecture.png   диаграмма архитектуры
```
